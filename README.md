Desenvolvimento de Aplicativo de Controle Financeiro para MEIs

Caio Bukvar

1. Introdução

O presente relatório tem como objetivo apresentar o desenvolvimento de um aplicativo básico de controle financeiro voltado para Microempreendedores Individuais (MEIs), criado durante a prática extensionista da graduação.

O projeto foi desenvolvido com foco em auxiliar pequenos empreendedores que possuem dificuldades no controle de receitas, despesas e acompanhamento financeiro do próprio negócio. Muitos MEIs realizam seus controles manualmente, utilizando papel, anotações dispersas ou até mesmo sem qualquer organização financeira, o que pode gerar prejuízos, descontrole de caixa e dificuldades administrativas.

A proposta do aplicativo é oferecer uma solução simples, intuitiva e acessível para auxiliar no gerenciamento financeiro básico do microempreendedor.

2. Problema Identificado

Durante pesquisas e observações sobre pequenos negócios e trabalhadores autônomos, foi identificado que muitos MEIs enfrentam problemas relacionados a:

Falta de organização financeira;
Dificuldade em controlar entradas e saídas;
Ausência de acompanhamento do saldo mensal;
Mistura entre finanças pessoais e empresariais;
Falta de ferramentas simples e gratuitas para controle financeiro.

Grande parte dos microempreendedores não possui conhecimento técnico ou financeiro avançado, o que torna importante o desenvolvimento de ferramentas simples e de fácil utilização.

3. Objetivo do Projeto

O objetivo principal do projeto foi desenvolver uma aplicação web simples para auxiliar MEIs no controle financeiro básico do negócio.

Os objetivos específicos incluem:

Permitir o cadastro de receitas;
Permitir o cadastro de despesas;
Exibir o saldo atualizado automaticamente;
Facilitar a visualização financeira do negócio;
Oferecer uma interface moderna e intuitiva.
4. Tecnologias Utilizadas

Para o desenvolvimento do sistema foram utilizadas as seguintes tecnologias:

Tecnologia	Finalidade
React	Desenvolvimento da interface
Vite	Ambiente de desenvolvimento
Tailwind CSS	Estilização da aplicação
JavaScript	Lógica da aplicação
Node.js	Execução do ambiente frontend
5. Desenvolvimento da Aplicação

O aplicativo foi desenvolvido utilizando React, com gerenciamento de estado através do hook useState.

A aplicação permite:

Cadastro de movimentações financeiras;
Separação entre receitas e despesas;
Atualização automática dos totais;
Exclusão de registros;
Cálculo automático do saldo final.

A interface foi construída com Tailwind CSS, proporcionando um layout moderno, responsivo e organizado.

O sistema possui:

Dashboard financeiro;
Cards de resumo;
Formulário para inserção de dados;
Listagem dinâmica das movimentações.
6. Funcionalidades Implementadas
Cadastro de Receitas

O usuário pode cadastrar valores recebidos pelo negócio, informando:

Descrição;
Valor da movimentação.
Cadastro de Despesas

O sistema permite registrar despesas do negócio, como:

Internet;
Energia;
Transporte;
Compra de materiais.
Cálculo Automático

O sistema realiza automaticamente:

Soma das receitas;
Soma das despesas;
Cálculo do saldo atual.
Exclusão de Movimentações

O usuário pode remover registros incorretos ou desnecessários de forma simples.

7. Impacto Social da Solução

A aplicação possui potencial impacto social ao auxiliar pequenos empreendedores na organização financeira do próprio negócio.

Entre os benefícios proporcionados estão:

Melhor controle financeiro;
Redução de prejuízos causados por desorganização;
Maior acompanhamento do fluxo de caixa;
Incentivo à educação financeira;
Facilidade de uso para pessoas sem conhecimento técnico.

Além disso, o sistema pode ser utilizado gratuitamente e adaptado futuramente para diferentes tipos de negócios.

8. Resultados Obtidos

Ao final do desenvolvimento, foi possível criar uma aplicação funcional capaz de:

Registrar receitas e despesas;
Atualizar os dados em tempo real;
Melhorar a visualização financeira do usuário;
Demonstrar a aplicação prática de tecnologias web modernas.

O projeto também proporcionou experiência prática no desenvolvimento frontend utilizando React e Tailwind CSS.

9. Possíveis Melhorias Futuras

Como evolução futura do sistema, podem ser implementadas funcionalidades como:

Banco de dados;
Login de usuários;
Armazenamento em nuvem;
Geração de relatórios PDF;
Dashboard com gráficos;
Controle de impostos do MEI;
Aplicativo mobile;
Integração com APIs financeiras.
10. Conclusão

O desenvolvimento do aplicativo permitiu aplicar conhecimentos técnicos em um contexto social relevante, oferecendo uma solução simples para um problema comum enfrentado por microempreendedores.

A prática extensionista contribuiu tanto para o aprendizado técnico quanto para a compreensão das necessidades reais da comunidade, demonstrando como a tecnologia pode ser utilizada para facilitar processos do cotidiano e melhorar a gestão de pequenos negócios.

O projeto atingiu seus objetivos principais, entregando uma aplicação funcional, intuitiva e com potencial de expansão futura.
