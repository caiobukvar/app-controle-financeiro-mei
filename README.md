# 💰 Controle Financeiro MEI

Aplicação web desenvolvida para auxiliar Microempreendedores Individuais (MEIs) no controle básico de receitas, despesas e saldo financeiro do negócio.

O projeto foi criado como prática extensionista acadêmica, com foco em solucionar uma dificuldade comum entre pequenos empreendedores: a falta de organização financeira.

---

# 📌 Problema Abordado

Muitos MEIs realizam o controle financeiro manualmente ou não possuem qualquer ferramenta de acompanhamento financeiro, o que pode gerar:

- Desorganização financeira;
- Dificuldade no controle de entradas e saídas;
- Falta de acompanhamento do saldo mensal;
- Mistura entre finanças pessoais e empresariais;
- Prejuízos causados por ausência de gestão financeira.

---

# 🎯 Objetivo do Projeto

Desenvolver uma aplicação simples, intuitiva e acessível para auxiliar pequenos empreendedores no gerenciamento financeiro do dia a dia.

---

# 🚀 Funcionalidades

- Cadastro de receitas;
- Cadastro de despesas;
- Cálculo automático do saldo;
- Exclusão de movimentações;
- Atualização em tempo real;
- Interface moderna e responsiva.

---

# 🛠️ Tecnologias Utilizadas

- React
- Vite
- Tailwind CSS
- JavaScript
- Node.js

---

# 📈 Impacto Social

O sistema busca facilitar o acesso de microempreendedores a ferramentas de organização financeira, promovendo:

- Melhor controle do fluxo de caixa;
- Maior educação financeira;
- Facilidade de gestão;
- Incentivo ao uso de tecnologia em pequenos negócios.

---

# 📚 Projeto Acadêmico

Projeto desenvolvido como prática extensionista, aplicando conhecimentos de desenvolvimento web para solucionar problemas reais da comunidade através da tecnologia.
